Project Overview

Women commuting alone, traveling late at night, or navigating unfamiliar public spaces often rely on reactive SOS tools that only act after an emergency occurs. SAKHI AI shifts the focus to proactive awareness—combining Machine Learning, Expert Systems, Generative AI, and Computer Vision into a privacy-conscious local web application.

11 Core Women's Safety Modules

1. Dashboard

Central hub displaying quick safety tools, system status, and clean white-lavender-pink navigation.

2. Journey Guardian

Active journey countdown timer that tracks expected arrival while open and triggers simulated check-in alerts.

3. AI Situation Analyzer

Evaluates user-described scenarios using TF-IDF + Naive Bayes classification and IF–THEN safety rules.

4. Safety Planner

Helps women organize safe travel checklists, emergency contacts, and route precautions locally.

5. Hazard Scanner

Uses OpenCV and YOLOv8n to inspect environmental surroundings and lighting without judging people.

6. AI Safety Chatbot

Conversational assistant powered by Gemini and Groq APIs for instant women's safety guidance.

7. Emergency Assistance

Quick-access simulated SOS alert workflow with saved local emergency contact persistence.

8. Safety Simulator

Interactive scenario practice helping users build confidence in handling uncertain situations.

9. Incident History

Stores situational logs locally in SQLite using Indian Standard Time (IST) for private reference.

10. Settings

Manages emergency contacts, local preferences, and application configuration.

11. Discreet Mode

One-click screen camouflage to protect user privacy when using the app in public spaces.

AI & Technical Architecture

  • Frontend: HTML, CSS, and JavaScript (with localStorage persistence).
  • Backend & Database: Python, Flask, Flask-SQLAlchemy, and local SQLite database.
  • Machine Learning & NLP: Scikit-learn with TF-IDF vectorization and Multinomial Naive Bayes text classification.
  • Expert System: Custom Python rule-based IF–THEN reasoning engine for structured precautions.
  • Generative AI / LLMs: Gemini API and Groq API for context-aware safety conversations.
  • Computer Vision: OpenCV, Pillow, and YOLOv8n (Ultralytics) for local object and environment detection.

Responsible AI & Ethics

  • No Crime Prediction: SAKHI AI provides situational precautions and never claims to predict crimes or guarantee 100% safety.
  • No Appearance-Based Bias: Hazard scanning evaluates environmental objects and lighting—never a person's appearance or intentions.
  • Transparent ML Scores: Confidence scores are presented strictly as text classification indicators, not real-world danger probabilities.
  • Clear Simulation Labels: Emergency SOS and journey alerts are clearly marked as simulations until verified telecom integrations are added.
